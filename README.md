# Smart Study Planner Web App

## Project Overview

Smart Study Planner is a simple web-based application designed to help students organize their study tasks effectively. The application allows users to add subjects, tasks, deadlines, and priority levels. Students can also mark tasks as completed and manage their study schedule in a more structured way.

This project is mainly focused on solving a common student problem: poor time management and lack of organized study planning.

---

## Problem Statement

Many students find it difficult to manage their study time properly. They often forget assignments, exam preparation tasks, and project deadlines. This can lead to stress, last-minute work, and poor academic performance.

A simple digital study planner can help students organize their tasks, track progress, and improve consistency in their studies.

---

## Objective

The objective of this project is to develop a simple and user-friendly web application that helps students plan and manage their study tasks.

The application allows users to:

- Add study tasks
- Select subjects
- Set deadlines
- Choose priority levels
- Mark tasks as completed
- Delete tasks when no longer needed
- Save tasks in the browser using LocalStorage

---

## Goal

The main goal of this project is to improve student productivity and time management.

The intended outcomes are:

- Better organization of study tasks
- Reduced stress before exams and deadlines
- Improved consistency in daily study habits
- Easy tracking of pending and completed tasks
- A simple and accessible digital planning tool for students

---

## Features

- Add new study tasks
- Enter subject name
- Add deadline date
